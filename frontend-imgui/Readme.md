# Frontend in C++ with `Dear ImGui`

[*Dear ImGui*](https://github.com/ocornut/imgui) is a bloat less GUI library by [@ocornut](https://github.com/ocornut)

It may not be very customizable for beginner of app UI in C++ than GTK and QT

**but** it look quite good with minimalism and used a lot in games and graphics works

So yeah, It is used **A LOT**

I have a tool *ImHex* for analyzing hex dumps and yes, It uses *ImGui*
